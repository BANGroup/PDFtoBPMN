## Выводы (из измерений)
- Docling DOCX даёт структуру (заголовки, списки, таблицы с ячейками, рисунки с файлом, надписи) за 1–4 с; по тексту совпадает с нашим разбором.
- Не даёт: автонумерацию, Visio, Excel, подписи рисунков, привязку надписей к фигурам, страницы для абзацев Word.
- Docling PDF как тело эталона на 4–7 п.п. хуже нашего разбора текстового слоя; колонтитулы отделяет частично.
- 2.131 заметно лучше 2.80 на DOCX (надписи 100 % против 62–82 %, больше картинок с файлом и таблиц, порядок); на PDF различия малы.

## Не проверялось
Листы замены; LibreOffice для DrawingML; VLM для картинок; причина отсутствия файла у 22–30 % рисунков; статистика по корпусу (по одному файлу на класс графики).
